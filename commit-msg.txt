add fire sale music rotation and HD texture set

Fire Sale draws a random track each time instead of always playing the same
one, and the mod now ships HD replacements for the reticles, equipment icons
and font atlases.

Fire Sale music:
- Four tracks: the stock song, a hip hop remix, a cut of 4 Minutes and a cut
  of We Are Number One
- The track that just played is held out of the next draw, so the same song
  never plays twice running. Straight random over four repeats a quarter of
  the time, which reads as the rotation being broken rather than as chance
- New RULES setting, FIRE SALE MUSIC: Randomized (default) or Default
- Default returns undefined rather than forcing a track, which leaves
  play_firesale_audio on the stock aliases and so reproduces stock behaviour
  exactly, announcer branch included
- Read once in init like the rest of the RULES tab, so it takes effect on the
  next game rather than mid-match
- Files renamed off the vanilla asset name: firesale_vanilla,
  firesale_hiphop, firesale_4_minutes, firesale_number_one

Why the draw happens once in start_fire_sale:
- Stock threads the music onto every "intercom" entity separately, so several
  alias rows sharing one name would have each speaker roll its own track and
  play them over the top of each other. The draw is made once when the fire
  sale starts and every intercom reads that one choice off level
- setup_firesale_audio is replaced as well as play_firesale_audio. Replacing
  the latter alone does nothing: its only caller is the stock copy of the
  former, and a stock script calling its own function binds to the stock
  copy. The chain from init down to playloopsound has to be file-local
- mus_fire_sale_rich has to stay defined in mod.all.aliases.csv. Dropping
  that row left every Richtofen game with a silent fire sale, because the
  base game does not supply the alias

Audio format, none of which the toolchain checks:
- Mono, 48kHz, 16-bit FLAC in 1024 sample blocks
- ffmpeg defaults to 4608 sample blocks, which links, packs and then plays
  back as audible glitching. Encode with -frame_size 1024
- Levelled to within 1.4 LU of each other measured by EBU R128 rather than
  by RMS, which had left one track 2.7 LU quieter than the rest

HD textures:
- 8 reticles and 15 equipment HUD icons as loose .iwi in images/, packed into
  mod.iwd by build.bat. No zone entry and no script reference needed
- 3 font atlases, which needed both an image, line in reimagined.zone and the
  .iwi. T6 images are streamed: the fastfile carries only an asset header,
  which is what overrides the base game's, while the pixels come from
  mod.iwd. A loose .iwi alone has no asset to attach to, and the menu keeps
  stock fonts
- Several equipment icons are MP-only and Zombies never draws them

Docs:

  current test status
- README.md documents the FIRE SALE MUSIC setting
