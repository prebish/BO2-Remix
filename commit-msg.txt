add RULES options tab and HD crosshair

Expose the fork's gameplay changes as in-game settings, so they can be
turned off without rebuilding.

RULES tab:
- New options tab beside MOD, holding gameplay settings rather than the
  per-player display settings MOD already has
- Starting Points (0 / 500 / 1000 / 5000), Free Perk Drop, Free Perk
  Rarity (Normal / Rare), Zombie Shield Health (Default / Rebalanced),
  Carpenter Repairs Shield, Max Ammo Fills Magazine, Legacy Box Guns
- Every default reproduces existing behaviour

Implementation notes:
- Settings gate behaviour only, never registration. A toggle that skipped
  include_powerup or a registerclientfield call would desync host and
  client and drop joiners with EXE_CLIENT_FIELD_MISMATCH
- Reads go through mod_setting(), which falls back to a passed default
  rather than trusting init order, since getDvarInt on an unset dvar
  returns 0 and 0 is meaningful for several of these
- Defaults are seeded both client side in InitArchiveDvars and server
  side in init_dvars, so dedicated servers and players who never open the
  menu still get sane values

Starting points:
- Generalised from the commented-out Nuketown prototype to every map and
  moved into _zm_reimagined.gsc
- Applied as "set the score to this figure" so the 0 choice removes the
  stock starting points; 500 means "leave it alone", because the stock
  starting score is not always exactly 500

HD crosshair:
- Third-party replacement side_small.iwi in images/, packed into mod.iwd.
  Applies only while the mod is loaded, and reverts by deleting the file

Docs:
- README gains a Rules section and a crosshair line
- BUILDING.md notes that images not named in zone_source travel only in
  mod.iwd, so the fast rebuild picks them up
- FORK.md records the new options and drops the test list to one item
